# 탈퇴 요청 영수증 조회 — 읽기 전용 확장

2026-09-16. 기존 요청/취소는 REQUEST_ONLY이며 계정을 삭제하지 않는다. 앱에서 취소 응답이 유실되었을 때 활성 요청이 사라졌다는 이유만으로 취소/삭제 성공을 추정하지 않도록 GET /account/closure-requests/:id를 추가한다.

JWT 및 DB 로그인 버전 검사, 요청 UUID 검사, user_id 소유권 조건, REPEATABLE READ + READ ONLY 트랜잭션을 사용한다. 비밀번호/내부 요청키/사용자 이메일은 반환하지 않는다. 실제 취소를 다시 실행하지 않고 REQUESTED/CANCELLED 영수증을 확인할 수 있다. 기존 요청/취소 경로·DB 구조·원본 데이터·권한·결제 게이트는 변경하지 않는다.

test/closure-read.postgres-spec.ts는 로컬 합성 DB의 실제 JWT/HTTP/SQL로 익명·잘못된 UUID·타인 요청·만료 세션 거절, 취소 결과 조회, 6회 동시 조회의 무변경을 검사한다. 테스트 실행 수와 최종 결과는 커밋별 CI 기록으로 확인한다. 이것은 실고객 계정 탈퇴, 보존기간 확정, 운영 계정 삭제, 스토어 정책 인수가 아니다.
