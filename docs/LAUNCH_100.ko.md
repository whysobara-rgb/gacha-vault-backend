# 가치가차 출시 100단계 · 인수 체크리스트 v1

기준일: 2026-09-16. 현재 42/100 완료, 미완료 58개, 출시 승인 아님.

각 인수조건을 1점으로 센다. 개발 공수·비용·매출 성공 확률의 백분율이 아니다. 번호는 항목 식별자이며 처음 42개가 순서대로 모두 완료됐다는 의미가 아니다. 테스트 개수·문서 개수·반복 실행 횟수는 점수로 추가하지 않는다. 이 표 작성 자체에도 점수를 부여하지 않는다. 완료 범위를 축소해 점수를 올리지 않는다.

DEV는 소스·합성/격리 시험 완료이다. LIVE는 실제 배포 환경, EXTERNAL은 실제 공급자/기기/서비스 검증, APPROVAL은 사업자·정책·심사 승인이다. DONE만 1점이며 OPEN/BLOCKED/VERIFYING은 모두 0점이다. BLOCKED는 현재 선행조건·권한·키·정책이 부족하다는 뜻이지 영구 불가라는 뜻이 아니다.

모든 항목을 완료하고 증거를 갱신해야 100이다. PG/스토어 적합성(50), 실제 백업·배포(53~60), 실결제(61~70), 실물 공급(71~80), 최종 보안·기기/성능 검수(81~90), 심사·개시 승인(91~100)을 다른 개발 점수로 대체할 수 없다. 100도 매출·수익 성공을 보장하지 않는다.

기준 앱: ddb9b211adc39b83a41748171d4e2561734fbf5c. 신규 기능 기준 서버: 47e0f55f996b2599fab58e1da33f335d64409368. 마지막 Render 직접 조회: f29e5e35455ee4a6f6cbc7428a7baae849ceab6c, DB 변경 6개. 새 코드는 미병합 PR에 있으며 실제 원본 DB·PG를 변경하지 않았다.

## 점진적 도달 기준과 우선순위

현재 42: 기본 기능·거래·관리자 개발과 격리 검증 중심. 출시 판정은 BLOCKED.
50: 남은 모바일 공백/접근성(9,10), 외부 알림 시험(30), 관리자 인증/환불(39,40), 실행 권한(48), 출시 범위와 판매 적합성 검토(49,50)를 마무리한다. 정책 검토와 실행 권한은 즉시 병행한다.
60: 51~60의 실제 백업/별도 복원/동일 커밋 배포/앱-관리자 연결 완료. 배포판 버전과 원본 권리를 확인한다.
70: 승인된 판매 모델에 대해 61~70의 PG 계약/연동/실제 취소/대사/소액 승인 검증 완료. 공개 판매를 뜻하지 않는다.
80: 71~80의 실물 공급·확률·보관·전환·복구·출고·반품을 연결하고 1인 운영 검수 완료.
90: 81~90의 본인확인/정책/보안/기기/성능/복구·종합 인수 완료.
100: 91~100의 서명 빌드·제출·승인·통제된 공개·운영 인수 완료. 전 단계 미완료가 있으면 100으로 표시하지 않는다.

PG/스토어 적합성 검토와 실제 원본 보호 실행 경로가 최우선이다. 실물 공급 모델 결정(71)은 설계 의존성이므로 70점까지 기다리지 않고 정책(49,50)과 함께 시작한다. 그 외 개발은 테스트 가능한 범위에서 진행한다. 금전 결제·유료 자원·원본 변경은 구체적인 승인과 보호조치 없이는 실행하지 않는다. 이 문서는 비동기 작업을 예약하지 않는다.

## 배포 버전 검사

`tools/release/deployment-probe.cjs`는 명시한 PROBE_ORIGIN의 /health/ready를 GET으로만 읽고 PROBE_EXPECTED_COMMIT와 비교한다. 인증정보를 보내지 않고 리다이렉트/과대 응답을 거절한다. 일반 HTTPS 사용, HTTP는 명시적인 로컬 시험만 허용한다.

서버는 Render의 RENDER_GIT_COMMIT 또는 다른 환경에서 설정한 APP_COMMIT_SHA를 공개 메타데이터로 표시한다. 값이 없거나 충돌하면 검증 불가다. 이는 환경에서 보고한 버전이지 암호학적 빌드 증명이 아니다. 실제 배포 기록과 대조해야 한다. 프로브 PASS도 DB/버전 확인일 뿐 실결제/출시 승인이 아니다.

`node tools/release/progress.cjs`는 이 표를 검사·집계한다. `--require-launch`는 하나라도 미완료이면 실패한다. 이 명령이 실제 증거를 자동 생성·승인하거나 서버의 결제 게이트를 변경하지 않는다.
