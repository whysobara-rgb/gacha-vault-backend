## 제외 범위와 별도 차단 항목

복원 DB는 사용자의 접근 제한된 로컬 환경이고 TCP 접속을 열지 않았다. 인증키·DB 접속정보·고객 행 값·백업 파일 자체는 공개 저장소나 채팅에 올리지 않았다. 위 체크섬은 무결성 추적값이며 비공개 증거의 진위나 보관 상태를 누구나 자동 검증할 수 있는 서명은 아니다.

원래 DB 객체의 소유자/ACL/클러스터 역할은 --no-owner/--no-acl 방식으로 생략했다. 고객 데이터 귀속 대조와 DB 운영 권한 복원을 혼동하지 않는다. 다른 장치에서의 백업/키 복구, 보존기간 승인, 운영 권한, 실제 로그인, 앱·관리자 연결, 실제 PG, 실제 서버 변경은 미완료다. 백업 이후 원본에 생긴 변경도 포함되지 않는다. 파일 삭제를 저장장치의 완전 소거라고 표현하지 않는다.

따라서 54번의 기존 완료 조건은 충족하지만, 53번의 보호 보관/보존 최종 인수, 55~60번의 원본 변경·배포·앱 연결, 89번의 운영 장애 복구 훈련을 함께 완료 처리하지 않는다. 체크리스트의 LIVE 범위 중 이 항목은 실제 원본 백업을 다룬 실증을 가리키며, 복원 장소가 클라우드였다는 뜻이 아니다.

기존 자료에서 발견한 판매 분류·환불 조건·창고 연결·관리자 권한의 공백은 임의로 메우지 않았다. 상용 거래 활성화 승인은 계속 보류한다.
